# 英語テスト工房 — GitHub Pages版

文法・難易度・問題形式から小問を選び、問題用紙と解答を作成する静的Webアプリです。

## プライバシー（重要）

- GitHubに置くのは **HTML / CSS / JavaScriptのみ**。問題集・PDF・問題データ（JSON）は置かないでください。
- 問題データはユーザーがサイト上でローカルJSONを読み込んで登録し、ブラウザの **IndexedDB** に保存します。外部サーバーへの送信処理はありません。
- GitHub Pagesは公開Webサイトです。URLを知っている人はアプリ画面を見られますが、他人のブラウザに保存された問題データは読み取れません。
- 別のブラウザや端末に移す場合は、アプリの「問題データの管理」からバックアップを書き出し、新しい端末で読み込んでください。
- **ブラウザの閲覧データ削除、シークレットモード、端末故障でデータを失う場合があります。** 定期的にバックアップしてください。
- 学校の成績や生徒の個人情報は取り込まないでください。これはテスト問題用のアプリです。

## 公開手順

1. GitHubに新しい **Public** リポジトリ `english-test-studio` を作成します。すでにある `submission-scanner` は変更しません。
2. このフォルダの `index.html`, `style.css`, `app.js`, `docx.js`, `assets/icon.svg`, `.nojekyll` をリポジトリ直下に保存します（ZIPそのものではなく中身を配置）。
3. リポジトリの **Settings → Pages** で **Deploy from a branch → main → /(root)** を選択し、保存します。
4. 公開後のURLを開き、右上の「問題データ」→「JSONファイルを読み込む」で **非公開のJSONファイルを自分のPCから選択**します。

## 使い方

- 「問題を選ぶ」では文法・難易度・問題形式で絞り込み、[追加] を押します。
- 右側のリストで↑↓による並べ替え、×による取り外しができます。
- 「紙面を確認」で大問と小問の番号を確認します。同じ問題形式はまとまった大問になり、小問は各大問内で(1)から振り直されます。
- 「問題／解答をWordでDL」で編集可能な .docx を生成します。印刷ボタンからPDF保存できます。
- 解答のない問題は解答用紙に **［解答未登録］** と表示し、推測した答えを自動生成しません。
- 「問題を手入力」で問題を追加・編集できます。変更は同じ端末内に保存されます。

### JSONインポート形式

```json
{
  "schemaVersion": 1,
  "questions": [
    {
      "id": "presentperfect-standard-1-1",
      "topic": "現在完了",
      "level": "標準",
      "type": "選択式空所補充",
      "instruction": "次の（　）に入る最も適当な語句を選びなさい。",
      "text": "This is an original sample sentence.",
      "choices": "ア A / イ B / ウ C",
      "answer": "イ B",
      "explanation": "",
      "source": "自作問題"
    }
  ]
}
```

※上の文章はコード形式の説明用です。問題集の実際の本文はこのリポジトリには含めません。

## 開発

ビルド不要・外部パッケージ依存なしのHTML/CSS/JavaScriptです。ローカルでの確認は `python -m http.server 8000` → `http://localhost:8000` を開いてください。Word出力はブラウザ内で生成し、外部サービスには送信しません。
